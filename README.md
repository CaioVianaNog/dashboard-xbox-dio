Sobre o projeto
O dashboard transforma dados brutos de vendas em informações visuais claras, permitindo uma análise rápida do desempenho comercial das assinaturas Xbox Game Pass e EA Play ao longo de 2024.

Estrutura do repositório
dashboard-xbox-dio/
├── dashboard_xbox.xlsx   # Planilha com a base de dados e o dashboard completo
└── README.md             # Documentação do projeto

Dados utilizados
A base contém 20 registros de vendas de assinaturas com as seguintes colunas:
ColunaDescriçãoIDIdentificador único da vendaDataData da compraProdutoXbox Game Pass ou EA PlayPlanoUltimate, Core, PC, Padrão ou ProDuraçãoMensal ou AnualPaísBrasil, EUA ou MéxicoValor (R$)Valor da assinaturaRenovaçãoSe o cliente renovou (Sim/Não)

O que o dashboard exibe

Receita Total — soma de todas as vendas do período
Total de Vendas — número de assinaturas vendidas
Ticket Médio — valor médio por venda
Taxa de Renovação — percentual de clientes que renovaram
Gráfico de colunas — receita mensal (Jan–Abr)
Gráfico de pizza — participação de cada produto na receita
Gráfico de barras — receita por plano de assinatura
Gráfico de pizza — proporção de renovações Sim × Não


Como reproduzir

Baixe o arquivo dashboard_xbox.xlsx
Abra no Microsoft Excel (recomendado) ou Google Sheets
Acesse a aba Dashboard para visualizar os gráficos e KPIs
Os dados ficam na aba Base — edite à vontade e os gráficos atualizam automaticamente
